# 견적·주문 / 결제 운영 가이드

## 지금 동작하는 것 (서버 불필요)
1. `page/shop.html` 에서 제품을 담음 (브라우저 localStorage 에 저장)
2. `page/quote.html` 에서 회사/담당자/이메일 입력 후 제출 → EmailJS 로 회사 메일(템플릿에 설정된 수신 주소)로 전송
3. 접수번호(`UQ-YYMMDD-XXXX`)가 화면에 표시되고 메일 본문에 포함됨. 전송 실패 시 메일 앱으로 보내기 링크 제공
4. 이후 가격·납기 회신, 결제는 계좌이체/세금계산서 등 기존 방식으로 진행

## 가격 표시
`data/products.json` 의 각 제품 `price`(숫자, 원 단위, 부가세 별도)와 `unit`(예: "1g")을 채우면 카드에 가격이 표시됩니다. 비워두면(`null`) "견적 문의"로 표시됩니다. 가격은 반드시 직접 확인된 값만 넣으세요.

## 카드 결제를 켜려면 (PortOne V2 예시)
정적 사이트(GitHub Pages)만으로는 **안전한 카드 결제가 불가능**합니다. 아래가 모두 필요합니다.
1. 사업자 준비: PG(포트원/토스페이먼츠 등) 가입·계약, 통신판매업 신고, 이용약관·환불정책·개인정보처리방침 페이지
2. PortOne 콘솔에서 **Store ID**, **채널 키** 발급 → `js/payment.js` 의 `PAYMENT_CONFIG` 에 입력 (둘 다 공개 가능한 값. **API Secret 은 절대 이 저장소에 넣지 마세요**)
3. 결제 검증 서버 1개(Cloudflare Workers / AWS Lambda 등):
   - `POST {paymentId, items}` 수신 → 서버에서 `data/products.json` 가격으로 금액 재계산
   - PortOne 서버 API(Secret 사용)로 `paymentId` 결제 건 조회 → 금액·상태 일치 확인 → 주문 확정 메일 발송
   - 불일치 시 거절/취소
4. `PAYMENT_CONFIG.enabled = true`, `verifyEndpoint` 에 서버 URL 입력
5. 반드시 PG 테스트 모드로 먼저 결제·취소·금액 위변조 시나리오를 시험

> 클라이언트(브라우저) 코드만으로 "결제 완료"를 믿으면 금액 조작이 가능합니다. 검증 서버는 필수입니다.

## 개인정보
견적 폼은 이름·회사·이메일·연락처를 수집합니다. 개인정보처리방침 페이지를 만들어 폼의 동의 문구 옆에 링크하세요.
